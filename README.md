<p align="center">
  A modern <b>World Atlas web application</b> to explore countries, flags, population,
  regions, and more in an interactive way.
</p>

<hr/>

<h2>✨ Features</h2>
<ul>
  <li>🌎 View all countries with flags</li>
  <li>🔍 Search countries by name</li>
  <li>🌐 Filter countries by region</li>
  <li>📊 Detailed country information</li>
  <li>📱 Fully responsive UI</li>
</ul>
